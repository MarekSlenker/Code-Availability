This repository stores scripts and commands used for the annotation of the *Cardamine amara* genome for the paper Sandean et al. 2026

# Repeat identification

Repetitive sequences were identified using a combination of de novo and homology-based approaches. For the de novo prediction, we constructed custom repeat library employing [HelitronScanner](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.HelitronScanner.sh), [LTR_FINDER](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.LTR_FINDER.sh), [LTR_retriever](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.LTR_retriever.sh), [MiteFinderII](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.mitefinder.sh), [RepeatModeler](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.RepeatModeler2.sh), and [SINE_Scan](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.SineScan.sh)  

The resulting repeat elements were classified using [RepeatClassifier](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.RepeatClassifier.sh) and subsequently [merged with known repeat elements from the Dfam (v3.9) and RepBase (v20181026) databases, 
queried for the Brassicaceae-associated repeat elements](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.queryRELibs.sh).  

Next, [vsearch](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.vsearch.sh) was used to cluster repeat elements and to generate a non-redundant repeat library. Finally, [RepeatMasker](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.RepeatMasker.sh) was used to mask the genome with the finalized repeat library.




# Evidence guided gene prediction
Prediction of protein-coding genes was performed using the repeat-masked genome with the combination of *ab initio*, homology-based, and transcriptome-based predictions. The *ab initio* prediction was carried out using [BRAKER3](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/2_GenomeAnnotation.BRAKER3.sh). 
BRAKER automatically trained Augustus and GeneMark-ETP based on RNA sequence alignments and reference proteins obtained from OrthoDB12’s Viridiplantae dataset and 
protein sequences from seven related species (see below). The RNA-seq data of *Cardamine amara* (NCBI accession numbers: SRR11977918, DRR111001, DRR166629-DRR166631, DRR216635-DRR216643, SRR26392757) were processed to remove low-quality reads using [fastp](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/2_GenomeAnnotation.fastp.sh) and aligned to the genome using [HISAT2](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/2_GenomeAnnotation.HISAT2.sh). For the homology-based approach, [GeMoMa](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/2_GenomeAnnotation.GeMoMa.sh) was used to generate gene models based on protein sequences from seven related species: *Cardamine hirsuta*, *Arabidopsis arenosa* (GCA_905216605.1), *Arabidopsis thaliana* (GCF_000001735.4), *Brassica napus* (GCF_020379485.1), *Brassica rapa* (GCF_000309985.2), *Raphanus sativus* (GCF_000801105.2), and *Thlaspi arvense* (GCA_911865555.2). 
For the transcriptome-based approach, the transcriptome was assembled using [StringTie](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/2_GenomeAnnotation.StringTie.sh), and coding regions were predicted using [TD2](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/2_GenomeAnnotation.TD2.sh).
Gene models from all three approaches were integrated using [EvidenceModeler](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/2_GenomeAnnotation.EVidenceModeler.sh) to produce the high-confidence set of protein-coding gene annotations. Finally, [PASA](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/2_GenomeAnnotation.PASA.sh) was used to update gene structures with untranslated regions and alternative splicing variation information.


# Functional annotation
Functional annotation of the protein-coding genes was conducted by aligning protein sequences against multiple databases, including [Kofam](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/3_functionAnnotation.kofam.sh), RefSeq, SwissProt, and TrEMBL, using [diamond](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/3_functionAnnotation.DIAMOND.sh), with e-value ≤ 1e-5 as threshold. Furthermore, [eggNOG-mapper](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/3_functionAnnotation.emapper.sh) was utilized to search for homologous genes in the eggNOG database, to add KEGG terms, Gene Ontology terms, and Pfam domains.
