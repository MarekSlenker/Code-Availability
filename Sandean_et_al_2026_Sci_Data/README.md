This repository stores scripts and commands used for the annotation of the *Cardamine amara* genome for the paper Sandean et al. 2026

# Repeat identification

Repetitive sequences were identified using a combination of de novo and homology-based approaches. For the de novo prediction, we constructed custom repeat library employing [HelitronScanner](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.HelitronScanner.sh), [LTR_FINDER](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.LTR_FINDER.sh), [LTR_retriever](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.LTR_retriever.sh), [MiteFinderII](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.mitefinder.sh), [RepeatModeler](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.RepeatModeler2.sh), and [SINE_Scan](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.SineScan.sh)  

The resulting repeat elements were classified using [RepeatClassifier](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.RepeatClassifier.sh) and subsequently [merged with known repeat elements from the Dfam (v3.9) and RepBase (v20181026) databases, 
queried for the Brassicaceae-associated repeat elements](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.queryRELibs.sh).  

Next, [vsearch](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.vsearch.sh) was used to cluster repeat elements and to generate a non-redundant repeat library. Finally, [RepeatMasker](https://github.com/MarekSlenker/Code-Availability/blob/main/Sandean_et_al_2026_Sci_Data/1_RepeatSequencesAnnotation.RepeatMasker.sh) was used to mask the genome with the finalized repeat library.




# Evidence guided gene prediction
Prediction of protein-coding genes was performed using the repeat-masked genome with the combination of ab initio, homology-based, and transcriptome-based predictions. The ab initio prediction was carried out using BRAKER3 (v3.0.8)45. BRAKER automatically trained Augustus (v3.5.0)46 and GeneMark-ETP (v1.02)47 based on RNA sequence alignments and reference proteins obtained from OrthoDB12’s Viridiplantae dataset13. The RNA-seq data of C. amara (NCBI accession numbers: SRR11977918, DRR111001, DRR166629-DRR166631, DRR216635-DRR216643, SRR26392757) were processed to remove low-quality reads using fastp (v0.20.1)48 and aligned to the genome using HISAT2 (v2.2.1)49. For the homology-based approach, GeMoMa (v1.9)50 was used to generate gene models based on protein sequences from seven related species: Cardamine hirsuta2, Arabidopsis arenosa (GCA_905216605.1), Arabidopsis thaliana (GCF_000001735.4), Brassica napus (GCF_020379485.1), Brassica rapa (GCF_000309985.2), Raphanus sativus (GCF_000801105.2), and Thlaspi arvense (GCA_911865555.2). For the transcriptome-based approach, the transcriptome was assembled using StringTie (v2.2.1)51, and coding regions were predicted using TD2 (v1.0.5)41. Gene models from all three approaches were integrated using EvidenceModeler (v2.1.0)52 to produce the high-confidence set of protein-coding gene annotations. Finally, PASA (v2.5.3)53 was used to update gene structures with untranslated regions and alternative splicing variation information. Combining the above steps, 25,573 and 25,330 protein-coding genes were finally annotated in haplome 1 and haplome 2, respectively (Table 5). 


# Functional annotation
Functional annotation of the protein-coding genes was conducted by aligning protein sequences against multiple databases, including Kofam54, RefSeq25, SwissProt, and TrEMBL55, using diamond (v2.1.11.165)56, with e-value ≤ 1e-5 as threshold. Furthermore, eggNOG-mapper (v2)57 was utilized to search for homologous genes in the eggNOG database, to add KEGG terms, Gene Ontology terms, and Pfam domains. According to this approach, a total of 99.64% (25,480 out of 25,573) and 99.70% (25,255 out of 25,330) of protein-coding genes were successfully annotated in the aforementioned databases for haplome 1 and haplome 2, respectively (Table 6).
